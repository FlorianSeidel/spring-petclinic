PC-13The application executes no DDL during startup. Schema migrations run as a pipeline step before the deployment rolls.failEffort L

What the rule requires

The application executes no DDL during startup. Schema migrations run as a pipeline step before the deployment rolls.

Applies to: Applications with a relational datastore.

Why the verdict is fail

Startup SQL initialization is configured with schema and data locations, and the deployed PostgreSQL profile sets that initializer to run always. The referenced PostgreSQL schema contains DDL, including CREATE TABLE and CREATE INDEX statements, so DDL runs on the application startup path.

Contract test: Migrations or DDL run as part of application startup.
